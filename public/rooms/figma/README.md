## 상태별 기준 프레임

- 데스크톱 목록: `3456:6861`, 빈 목록: `3456:5294`
- 모바일 목록: `3314:5275`, 빈 목록: `3456:5419`
- 오버레이 S 기본 `Overlay`: `3449:3613`, `Overlay/Hover`: `3449:3579`
- 오버레이 L(프로필): `3314:3242`
- 오버레이 S 화면 내 위치: `3562:2283` (44px 메뉴 영역 기준 right 10px, top 42px)

요청에 따라 빈 목록 이미지 영역은 파란 우때 심볼로 대체하고, 모바일 여행 생성을 허용하며, 푸터의 기존 쿠키 설정 링크는 유지한다. 모바일 상태바와 홈 인디케이터는 OS 영역이므로 웹 콘텐츠에 복제하지 않는다.
