# 랜딩페이지 제품 화면 캡처

- 적용일: 2026-09-11
- 새 캡처: [Figma 3157:1204](https://www.figma.com/design/uJLn6DbZ6MMpWyfuOXr6wu/Uttae?node-id=3157-1204)
- 기존 화면 참고: [Figma 3157:1188](https://www.figma.com/design/uJLn6DbZ6MMpWyfuOXr6wu/Uttae?node-id=3157-1188)

최상단 이미지는 사용자가 제공한 `스크린샷 2026-09-11 오후 8.09.39.png`(2880×1900px)를 원본 그대로 사용한다. 파란 프레임과 둥근 모서리는 CSS로 표시하며, 화면 안쪽은 왼쪽 위를 기준으로 `object-fit: cover`를 적용한다. 원본을 750×567px로 축소 저장하지 않아 레티나 화면에서도 충분한 해상도를 제공한다.

나머지 PC는 `3149:1182`, 모바일은 `3157:1182`의 원본 PNG를 사용한다. PC 원본은 3416×1896px이며, Figma의 CROP 변환(`imageTransform[0][0] = 0.8153241873`)에 따라 왼쪽부터 2785×1896px를 사용한다. 모바일 원본은 612×1268px다.

| 파일 (`public/landing/figma/`) | 사용 위치 | 출력 크기 |
| --- | --- | --- |
| hero-web-retina.png | 첫 화면의 파란 테두리 웹 화면 | 2880×1900 (CSS 프레임 최대 750×567) |
| laptop-current.png | 해결책 소개의 노트북 화면 | 1984×1208 |
| schedule-current.png | STEP 2 일정·동선 소개 | 1888×1416 |
| web-current.png | PC·모바일 소개의 PC 화면 | 1500×1133 |
| phone-current.png | PC·모바일 소개의 휴대폰 화면 | 444×929 |

최상단을 제외한 이미지는 기존 외곽 프레임과 출력 크기를 유지하고 화면 내부에 새 캡처를 합성했다. PC는 왼쪽 위, 모바일은 중앙을 기준으로 비율을 유지해 화면 영역에 맞춘다. 랜딩페이지의 배치·CSS 크기는 유지한다. 파일명을 변경해 이전 이미지 URL의 캐시와 구분한다.

최상단의 CSS 프레임은 750×567 기준 화면 영역 `(10, 10, 730, 547, 20)`을 비율로 유지한다. 나머지 합성한 화면 영역은 원본 PNG 기준 `(x, y, width, height, radius)`로 각각 laptop `(175, 36, 1632, 1076, 40)`, web `(16, 16, 1468, 1101, 42)`, phone `(14, 14, 416, 901, 34)`다. schedule은 새 PC 캡처를 프레임 없이 사용한다.

검색·북마크 소개는 사용자가 별도로 제공한 캡처 2개를 원본 그대로 저장해 사용한다. `search-places-current.png`(752×892px, 카페 장소 목록)를 뒤쪽 왼쪽 위에, `search-folders-current.png`(698×510px, 관광지·카페·음식점 폴더 목록)를 앞쪽 오른쪽 아래에 배치한다. 기존 731×564 비율의 영역 안에서 CSS로 겹치며 모바일에서도 같은 순서와 비율을 유지한다.

새 채팅 캡처가 없으므로 `chat.png`는 기존 파일을 유지한다. 문제 소개의 여러 창 이미지, 일러스트, 로고와 배경 장식도 이번 교체 범위에 포함하지 않는다.
