선택적 비용 이름은 메모와 별개다. 이름이 비어 있으면 제목과 이름 입력 placeholder는 **카테고리 이름만** 사용한다. 연결 장소나 메모를 이름으로 사용하지 않으며 표시용 기본값을 저장하지 않는다. FOOD의 UI 라벨은 디자인에 따라 식비다.

이름은 원문 기준 UTF-16 100자 이내다. Java whitespace를 양끝에서 제거하고 빈 값은 null로 저장한다. NBSP는 유지한다. POST는 선택적 이름을 보내며 PATCH에서 변경하지 않은 이름은 생략해 보존하고, 사용자가 지운 이름은 null로 보낸다. 메모의 빈 문자열과 이름 변경은 독립적이다. 기존 expectedVersion 충돌 복구를 유지한다.

GET /rooms/{roomId}/expenses/summary/krw의 상세 응답으로 행·카테고리·일차·결제자 원화 합계를 표시한다. 상단 예산/카테고리 및 정산은 필터 없는 전체 방 응답, 목록은 expenseGroup/scheduleId/category의 AND 필터 응답을 사용한다. 필터 응답의 최상위 합계도 전체 방이므로 선택 범위에는 filtered를 사용한다. 각 응답의 날짜/ECB 출처/이전 환율 여부를 별도 표시하며 서로 다른 요청을 같은 환율 스냅샷으로 간주하지 않는다.

서버는 원통화 집계 후 환산·반올림한다. 501원 행 두 개의 합계가 1,001원일 수 있으며 프론트에서 반올림된 행/그룹을 합산하거나 총액에서 환율을 역산하지 않는다. 결제자 합계 역시 서버가 원통화 최소 단위로 분할한 결과다. 원통화 정산·부담·송금은 기존 정산 응답을 유지한다.

부분 금액에는 '부분 합계'와 누락 통화를 표시한다. null은 환산 불가이며 '0'은 실제 반올림 결과로 표시한다. 부분 0원은 완전한 0원과 구분한다. 남은 예산은 동기화 완료·완전 환산·최신 환율일 때만 계산한다. 실패한 요청/동기화는 재시도 안내를 제공하며 필터별 캐시도 기존 무효화·재연결·주기 갱신과 권한 철회 대상이다.
