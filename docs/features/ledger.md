# 가계부 표시와 연동 범위

비용 이름은 선택 사항이며 메모와 별개다. 이름이 비어 있으면 제목과 이름 입력 placeholder는 **카테고리 이름만** 사용한다. 연결 장소명이나 메모를 이름 대신 사용하지 않는다. 표시용 기본값을 이름으로 자동 저장하지 않는다. 메모와 연결 장소는 각각 별도 정보로 유지한다.

현재 프론트엔드의 비용 계약에는 이름 필드가 없다. 따라서 현재 목록은 카테고리 이름을 표시하며, 저장되지 않는 이름 입력란은 제공하지 않는다. 확정된 백엔드 API/DTO를 받은 뒤 선택적 이름 입력·조회·수정을 연결하고 위 placeholder 규칙을 적용한다.

항목·카테고리·일차·개인별 원화 환산은 **백엔드에서 계산한다**. 상세 응답 계약이 제공되기 전에는 기존 원통화 금액과 정산 응답을 유지한다. 총액에서 환율을 역산하거나, 임의 환율·샘플 원화 금액을 사용하거나, 서로 다른 통화를 합산하지 않는다.

이름 저장 및 상세 원화 응답 연동이 남아 있으므로 현재 UI 구현만으로 전체 가계부 작업이 완료된 것은 아니다.
