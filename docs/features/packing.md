# 개인 준비물

## 접근과 목록 범위

개인 준비물은 `/packing/{roomId}` 주소와 데스크톱 사이드바의 "준비물" 메뉴로 접근합니다. 모바일에서는 하단 "여행 도구" 탭의 "가계부"·"준비물" 메뉴로 화면을 전환할 수 있습니다. 목록은 로그인 사용자와 방에 한정되며, 서버의 응답 순서와 내용을 사용합니다.

최초 조회가 `PACKING_LIST_NOT_INITIALIZED`인 경우에만 초기화를 요청하고, 비어 있는 기존 목록은 그대로 유지합니다.

## 저장과 동기화

준비물은 REST로만 동기화합니다. 저장은 목록 버전으로 직렬 처리합니다. 저장 결과가 불확실하거나 후속 조회가 실패하면 추가 저장을 중단하고 다시 동기화할 수 있습니다. 충돌 뒤에는 최신 내용을 확인하여 명시적으로 다시 저장해야 합니다.

## 삭제와 초안

카테고리와 준비물은 최신 내용을 다시 조회한 뒤 사용자 확인을 받아 삭제합니다. 삭제 후 실행 취소 기능은 제공하지 않습니다. 입력 중인 초안은 메모리에만 유지합니다.
